# Aritz Tusell

### Engineering Manager · Senior Developer · Barcelona, Spain

Engineering manager who still enjoys getting hands-on. I lead small multidisciplinary
teams through the full development lifecycle while staying close to system architecture,
cloud infrastructure and data-extraction pipelines. Fifteen-plus years of learning across
engineering leadership, web scraping, data processing and full-stack development.
Still learning, though. 🙂

Right now I'm Technical Engineering Manager at HelioVolta / SolarGrade, leading a small
team of backend and frontend engineers. We build a mobile app for in-field incident
management at commercial solar plants, with Python, Django, Angular and Kotlin on Azure.

## What I do

- Manage and mentor engineering teams, set the technical roadmap, run agile delivery and
  own projects from start to finish.
- Design systems and run them on Azure: infrastructure, CI/CD pipelines and automation,
  and migrations from legacy stacks to a single Python/PostgreSQL one.
- Extract data at scale: Scrapy with custom middleware, anti-bot countermeasures, proxy
  and header rotation, cleaning and normalization, pipeline design and API integration
  (REST, SOAP, XML-RPC).

Day to day: Python, Django, FastAPI, Scrapy and PostgreSQL, usually on Azure, plus
Angular and Odoo.

## Some things I've built

At OTA Insight (Ghent, Belgium) I was part of a specialist team scaling a network of web
crawlers against dynamic, heavily protected sites. I wrote custom Scrapy middleware for
pub/sub queue management and anti-bot countermeasures, and worked on the metrics and
real-time alerting tooling.

As hands-on CTO at CymitQuímica I helped design and build a modular extraction system that
scraped and updated hundreds of thousands of chemical product records daily from dozens of
international suppliers. I also took part in the migration from Java, PHP and several SQL
databases to Python/PostgreSQL, including an ERP migration to Odoo and a new Django
e-commerce platform.

I co-founded Timtul, a Django platform for associations that is still in use today. It lets
administrators manage thousands of members, their responsive website and their
communications. I built the core web and mail builder tools.

At BMAT I worked on a high-volume processing framework that integrated thousands of new
audio files and metadata every day, across XML, DDEX, FTP, SOAP and XML-RPC.
